# [서비스 기획서] SNU Study Cafe (서울대 카공 뽀모도로)

## 1. 서비스 개요
- **서비스명**: **SNU Study Cafe (서울대 카공 뽀모도로)**
- **기획 의도**: 공간의 제약 없이 언제 어디서나 서울대학교 캠퍼스 명소의 분위기를 느끼며 몰입할 수 있는 디지털 카공(카페 공부) 환경 제공.
- **배포 채널**: 서울대학교 공식 인스타그램 프로필 링크를 통한 웹 배포
- **주요 디바이스 타겟**: 대학생의 실질적 학습 환경인 **노트북(데스크톱) 와이드 뷰를 메인**으로 하되, 인스타그램 인앱 브라우저를 통한 **모바일 환경에도 완벽 대응**하는 반응형 웹.
- **타겟 사용자**: 
  - 집중력 있는 공부 및 작업 환경이 필요한 서울대학교 학우 및 수험생
  - 일상에서 서울대 캠퍼스(도서관, 카페, 연못)의 앰비언트 무드를 경험하고 싶은 모든 사용자

---

## 2. 페이지 및 섹션 구성 (3개 섹션)
단일 페이지 애플리케이션(SPA) 구조 내에서 네비게이션을 통해 매끄럽게 전환되는 3개 섹션으로 구성됩니다.

| 섹션명 | 구성 요소 및 주요 기능 |
| :--- | :--- |
| **① 스터디 데스크 (Study Desk)** | • **4대 스팟 앰비언트 영상 배경** (자하연, 잔디광장, 관정도서관, 사회대 16동 라운지)<br>• **뽀모도로 타이머** (25분 집중 / 5분 휴식, 시작·일시정지·리셋)<br>• **학내 앰비언트 사운드 믹서** (물소리, 도서관 소음, 카페 백색소음, 빗소리 등)<br>• **데스크 위 주문 음료** (섹션 ②에서 주문한 음료가 책상 한편에 렌더링) |
| **② 느티나무 카운터 (Cafe Counter)** | • **느티나무 카페 인기 음료 주문 키오스크**<br>• 사용자의 공부 목표 및 컨디션 입력 UI<br>• **Gemini AI 바리스타 맞춤 주문서 & 동기부여 영수증 발행** |
| **③ 캠퍼스 스팟 도감 (Campus Guide)** | • 4대 스팟 실제 정보 및 분위기 소개, 카공 꿀팁<br>• 뽀모도로 학습법 가이드 및 오늘 누적 세션 기록 |

## 3. 핵심 기능 상세

### 3.1. 4대 스팟 앰비언트 영상 배경
- **배경 장소**:
  1. **자하연**: 연못의 잔잔한 물결과 수목이 주는 편안한 자연 무드
  2. **잔디광장**: 본부 앞/버들골의 탁 트인 하늘과 살랑이는 잔디 힐링 무드
  3. **관정도서관**: 모던한 서가와 정갈한 열람실의 차분한 학구적 무드
  4. **사회대 16동 라운지**: 관악산 통창 뷰와 따뜻한 조명이 감도는 세련된 라운지 무드
- **기술적 특징**:
  - HTML5 `<video autoplay loop muted playsinline>` 기반 무한 루프 앰비언트 영상.
  - 모바일 인앱 브라우저 자동 재생 규격 준수 (`muted`, `playsinline`).

### 3.2. 뽀모도로 타이머 & 앰비언트 사운드
- 기본 25분 집중 / 5분 휴식 인터벌 타이머.
- 웹 오디오 API 또는 Audio 객체를 통한 볼륨 조절 및 다중 사운드 제어.

### 3.3. 서울대학교 느티나무 카페 연계 음료
실제 서울대학교 교내 카페인 **느티나무(Neutinamu)**의 대표 인기 음료 라인업 반영:
- **리딸라 (리얼딸기라떼)**: 달콤하고 든든한 당 충전 대표 메뉴
- **말차라떼**: 차분하게 마음을 가라앉히는 쌉싸름한 힐링 메뉴
- **아이스 아메리카노**: 시험 기간 관정 열람실 필수템, 깔끔한 카페인 부스터
- **카페라떼**: 부드러운 목넘김으로 오래 지속되는 집중력을 돕는 메뉴

## 4. AI 기능 설계 (Gemini API 연동)

### 4.1. 기능 개요: AI 바리스타 맞춤 처방 & 동기부여 영수증
- **목적**: 사용자가 공부 목표와 현재 컨디션을 입력하면, Gemini AI가 사용자의 상태에 꼭 맞는 느티나무 음료 커스텀 추천과 함께 따뜻하고 감성적인 동기부여 영수증을 발행.
- **호출 구조**: 프론트엔드 `fetch('/api/order')` → 백엔드 Vercel Serverless Function (`api/order.py`) → `Google Gemini API (gemini-1.5-flash)`.

### 4.2. 입·출력 스펙
- **입력 (Request Body)**:
  - `task` (문자열, 필수): 오늘 공부할 내용 (예: "미적분학 기말 과제 풀기")
  - `condition` (문자열, 필수): 현재 컨디션 (예: "피곤하고 잠이 쏟아짐", "의욕 넘침", "잡생각이 많음")
  - `drinkPreference` (문자열, 선택): 선호 음료 카테고리 (커피/논커피/티/상큼한 음료)
- **출력 (JSON Response)**:
  - `recommendedDrink`: 맞춤 느티나무 음료명 (예: "리얼딸기라떼 (리딸라)")
  - `drinkTagline`: 한 줄 설명 (예: "지친 뇌세포에 즉각적인 당 충전이 필요한 순간")
  - `motivationMessage`: 따뜻하고 담백한 동기부여 응원 문구 (인위적인 선배 호칭 제외, 순수한 몰입과 격려 중심)
  - `studyTip`: 이번 뽀모도로 세션에 도움 되는 가벼운 팁 1가지

### 4.3. 예외 및 실패 처리 기준 (과제 요구사항 준수)
1. **필수 입력값 누락 (빈 입력)**:
   - 목표 또는 컨디션 미입력 시 API를 호출하지 않고, 입력 필드 하이라이트 및 안내 문구 출력: *"바리스타에게 어떤 공부를 할지 알려주세요."*
2. **응답 지연 및 대기 (Loading / Timeout)**:
   - 주문 버튼 클릭 즉시 로딩 인디케이터 표시: *"원두를 내리고 맞춤 주문서를 작성하고 있습니다..."*
   - 8초 초과 시 사용자 안내 및 재시도 옵션 제공.
3. **API 에러 (4xx / 5xx, 네트워크 단절 등)**:
   - 에러 발생 시 부드러운 팝업 안내: *"바리스타가 잠시 자리를 비웠습니다. 스테디셀러인 '아이스 아메리카노'로 준비해 드릴게요!"*
   - 기본 영수증(Fallback)을 즉시 렌더링하여 학습 흐름이 끊기지 않도록 방어.

## 5. 기술 스택 및 디렉토리 구조

### 5.1. 기술 스택
- **프론트엔드**: HTML5, CSS3 (Flexbox/Grid, Dynamic Viewport Height `dvh`), Vanilla JavaScript (ES6+)
- **백엔드**: Python 3.9+, Vercel Serverless Functions (`api/order.py`)
- **AI 연동**: `google-genai` 또는 `google-generativeai` (Gemini 1.5 Flash)
- **배포 플랫폼**: Vercel (GitHub 리포지토리 연동)
