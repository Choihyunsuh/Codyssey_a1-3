# [서비스 기획서] study with SNU

## 1. 서비스 개요
- **서비스명**: **study with SNU**
- **기획 의도**: 공간의 제약 없이 언제 어디서나 서울대학교 캠퍼스 명소의 앰비언트 영상과 전용 사운드 속에서 몰입할 수 있는 감성 카공 뽀모도로 웹 서비스.
- **배포 채널**: 서울대학교 공식 인스타그램 프로필 링크를 통한 웹 배포
- **주요 디바이스 타겟**: 대학생의 실질적 학습 환경인 **노트북(데스크톱) 와이드 뷰를 메인**으로 하되, 모바일 인앱 브라우저 환경에도 최적화된 반응형 웹.
- **디자인 컨셉**:
  - 온글잎 민혜체 기반의 아기자기하고 따뜻한 손그림(Doodle Line Art) 감성
  - 따뜻한 크림/버터 베이지, 우디 브라운, 세이지 그린, 연한 레몬버터 컬러 팔레트
  - 풍경 중심의 시원한 뷰 + 화면 가운데 하단 커피 오브젝트 & 말풍선 배치

## 3. 핵심 기능 상세

### 3.1. 4대 스팟 앰비언트 영상 & 맞춤 사운드 자동 송출
사용자가 스팟을 선택하면 해당 장소의 고유 사운드가 자동으로 전환 송출됩니다:
1. 🌊 **자하연**: 연못 물결 & 토닥토닥 빗소리 레이어드
2. 🌿 **잔디광장**: 버들골의 시원한 바람소리 & 자연 야외 소음
3. 📚 **관정도서관**: 정갈한 열람실 서가의 깊은 도서관 화이트노이즈
4. ☕ **사회대 16동**: 통창 라운지의 따뜻한 카페 소음

### 3.2. 콤팩트 뽀모도로 타이머
- 시각적 개방감을 해치지 않는 상단 중앙의 아담한 미니 위젯.
- 25분 집중, 5분 휴식, 15분 긴 휴식 모드.
- 세션 완료 시 청아한 차임벨 울림 및 LocalStorage 누적 달성 카운트.

## 4. AI 기능 설계 (Gemini API 연동)

### 4.1. 기능 개요: AI 바리스타 맞춤 처방 & 동기부여 영수증
- **호출 구조**: 프론트엔드 `fetch('/api/order')` → 백엔드 Vercel Serverless Function (`api/order.py`) → `Google Gemini API (gemini-3.5-flash-lite)`.
- **입력 스펙**:
  - `name`: 주문자 이름 (닉네임)
  - `subject`: 공부할 과목
  - `goal`: 오늘의 세부 목표
  - `condition`: 이모지 컨디션
  - `mood`: 희망 무드 (집중, 마감, 힐링, 독서)
  - `drinkPreference`: 선택 음료 (리딸라, 말차라떼, 아메리카노, 카페라떼, 자몽허니티)
- **출력 스펙**:
  - `recommendedDrink`: 음료명
  - `motivationMessage`: 다정하고 따뜻한 1~2문장 손글씨 응원

### 4.2. 실패 처리 기준
1. **과목 필수값 누락**: 안내 토스트 및 입력 필드 포커스
2. **지연 및 대기**: 흔들리는 커피잔 로딩 애니메이션
3. **API 오류 및 네트워크 단절**: 스마트 Fallback 영수증 자동 생성으로 끊김 없는 학습 지원

## 5. 기술 스택
- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript (ES6+), 온글잎 민혜체 웹폰트

- **AI 연동**: Google Gemini (`gemini-3.5-flash-lite`) REST API
